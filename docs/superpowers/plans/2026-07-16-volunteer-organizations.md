# Volunteer Organizations (Malvern) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add multi-organization support scoped to volunteers, so a sign-up with an `@malvernprep.org` email auto-joins a seeded "Malvern" organization, and org admins get an org-scoped roster, impact stats, and announcements — while restaurants, drop-offs, and the food path stay global.

**Architecture:** A new `Organization` table with an optional unique `emailDomain`; `User.organizationId` and `Announcement.organizationId` FKs. A pure-ish resolver (`orgForEmail`) maps a sign-up email to an org (domain match, else the single `isDefault` org). Volunteer-facing surfaces (audience resolution, volunteer impact stats, admin roster) each gain an `organizationId` filter; restaurants/drop-offs/listings/pickups and the partner-approval queue are untouched. Org membership is resolved from the acting user's own DB row at request time — never threaded through the NextAuth session.

**Tech Stack:** Next.js 14 App Router, TypeScript, Prisma + PostgreSQL (Supabase), NextAuth. Tests: `node --test` via tsx with injected `deps.db` fakes (no live DB).

- **Test runner:** `npm test` runs `node --require ./lib/stub-server-only.cjs --import tsx --test lib/*.test.ts lib/analytics/*.test.ts`. import type { PrismaClient } from "@prisma/client";
```ts
import { prisma } from "./prisma";

type OrgDb = Pick<PrismaClient, "organization">;
type OrgLite = { id: string; name: string };

export async function defaultOrg(deps: { db?: OrgDb } = {}): Promise<OrgLite> {
  const db = deps.db ?? prisma;
  const org = await db.organization.findFirst({ where: { isDefault: true } });
  // The migration always seeds exactly one default org; this should never be
  // null in a migrated database.
  if (!org) throw new Error("No default organization is configured.");
  return { id: org.id, name: org.name };
}

// Which org a sign-up email joins: the org whose emailDomain matches (case-
// insensitive), else the default. Never returns null.
export async function orgForEmail(
  email: string,
  deps: { db?: OrgDb } = {}
): Promise<OrgLite> {
  const db = deps.db ?? prisma;
  const at = email.lastIndexOf("@");
  const domain = at === -1 ? "" : email.slice(at + 1).trim().toLowerCase();
  if (domain) {
    const match = await db.organization.findUnique({ where: { emailDomain: domain } });
    if (match) return { id: match.id, name: match.name };
  }
  return defaultOrg({ db });
}
```

```ts
import type { PrismaClient } from "@prisma/client";
import { prisma } from "./prisma";

type OrgStatsDb = Pick<PrismaClient, "pickup">;

// Volunteer-facing impact for one organization: totals over delivered pickups
// carried by that org's volunteers. Non-punitive by design — aggregate counts,
// never per-person grades. Restaurants/drop-offs are global and excluded here.
export async function getOrgVolunteerImpact(
  organizationId: string,
  deps: { db?: OrgStatsDb } = {}
): Promise<{ meals: number; volunteers: number; pickups: number }> {
  const db = deps.db ?? prisma;
  const rows = await db.pickup.findMany({
    where: { deliveredAt: { not: null }, volunteer: { organizationId } },
```

```ts
// Roster scoping for org admins: they see and act on only their own org's
// volunteers/admins. Partners (restaurant/drop_off) are global and never pass
// through here.
export function orgVolunteerWhere(
  organizationId: string,
  role: "volunteer" | "org_admin"
): { role: string; organizationId: string } {
  return { role, organizationId };
}

// Cross-org guard: an actor may act on a target only when both belong to the
// same non-null org.
export function assertSameOrg(
  actorOrgId: string | null,
  targetOrgId: string | null
): boolean {
  return actorOrgId != null && targetOrgId != null && actorOrgId === targetOrgId;
}
```
